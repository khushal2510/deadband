Revision codes

IFRIssued for review: internal or client comment round.
IFAIssued for approval: client sign-off before the work proceeds.
IFCIssued for construction: released to build.
ABAs-built: updated to match what was installed.

Typical coding. Clients define their own, so use the document control procedure.

Surviving client-specific formats

  • Get the client templates, tag numbering rules and units before the first datasheet, not after the first comment sheet.
  • Keep one master instrument index and generate other documents from it.
  • Answer every comment on a comment resolution sheet with a clear status, even if the answer is noted.
  • Raise a technical query early when two client documents conflict. Record the answer and date.
  • Track vendor documents weekly against the VDRL.

Tag decoder

Instrument tags follow ISA-5.1: first letter for the measured variable, optional modifier, then the function letters. Type a tag to read it.

Source: ISA-5.1, instrumentation symbols and identification. Companies add their own conventions for unit, area and loop numbering, so follow the project tag procedure.
