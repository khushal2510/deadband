# Deadband

A small website for instrumentation and control engineers: somewhere to take a few minutes away from the deadline, and a place to find reference material when you need it.

**Live site:** https://khushal2510.github.io/deadband/

## What's in it

- **Unwind** – breathing exercise, plant ambience mixer, a small quiz, a memory game and a break timer.
- **Galaxy** – a simple solar system view with notes on each planet.
- **Field guide** – measurement technologies, calculators (4–20 mA, DP level, orifice, Cv, RTD and others) and a loop troubleshooting guide.
- **Safety** – HAZOP deviation builder, risk matrix, SIL and LOPA basics, hazardous area notes.
- **Machinery** – compressor types, surge and anti-surge, protection and vibration.
- **Desk** – deliverables checklist, project workflow, glossary and tag decoder.

## A note on the content

Values are typical or illustrative. Always follow your project specification, the editions of the standards your client names, vendor documentation and your company procedures. The calculators are for quick sanity checks, not for replacing a sizing tool or datasheet.

## Running it locally

It is plain HTML, CSS and JavaScript with no build step. Open `index.html` in a browser, or serve the folder with any static server.

## Hosting

Deployed with GitHub Pages from the root of the `main` branch. The `.nojekyll` file is there on purpose, so keep it.
